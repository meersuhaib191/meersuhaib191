### 🌟 Projects

#### [LIBRARY MANAGEMENT SYSTEM](http://lm.free.nf)

A comprehensive web-based library management system designed to streamline and automate library operations. This system provides a user-friendly interface for librarians, administrators, and patrons to manage and access library resources efficiently.

**Key Features:**
- User authentication and authorization for librarians, administrators, and patrons
- Cataloging and searching of books, journals, and other library materials
- Book borrowing and return management

**Tech Stack:**
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: PHP
- Database: SQL

---

#### [HOSTEL EASE](https://meersuhaib191.github.io/hostel-ease)

A comprehensive web-based hostel management system designed to streamline and automate hostel operations. Built using HTML, CSS, PHP, Bootstrap, JavaScript, and SQL, this system provides a user-friendly interface for administrators, staff, and residents to manage and access hostel resources efficiently.

**Key Features:**
- User authentication and authorization for administrators, staff, and residents
- Room allocation and management for students
- Responsive design for accessibility on various devices

**Tech Stack:**
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: PHP
- Database: SQL
